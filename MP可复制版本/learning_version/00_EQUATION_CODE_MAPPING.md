# 论文式 (16)–(41) 与 MATLAB 代码映射

## 读表规则

本表依据论文 PDF 正文第9–13页、六个原始 `.m` 文件和 MAT 元数据。论文式 (16)–(33) 多为**水平值模型的推导**，代码主要实现式 (34)–(41) 的**相对变化（hat）系统**；因此“代码没有逐字出现水平值公式”不等于论文与代码冲突。

映射强度：

- **直接**：代码中有同一经济恒等式或其明确 hat 版本；
- **间接/校准**：对象存在，但水平值推导被份额、参数或基期数据吸收；
- **未确认**：未能从现有代码中无歧义确认，绝不按名称猜测。

文件缩写：`01` 主校准，`02` 迭代器，`03` 均衡更新，`04` MP-only，`05` 重新计算，`06` 福利分解。

## 式 (34)–(41) 的代码流

```text
(34) hw_E + hP_int + hgamma (+ hkappa) → hxi_4d = hat(tau*c)
                                      ↓
(37) psi_4d 加权跨生产地聚合 → hPsi_3d；归一化 → hpsi_4d
                                      ↓
(35)-(36) lam_3d × hN × hPsi → hP_new
                                      ↓
          hN × hPsi 归一化 → hlam_3d
                                      ↓
          X_4d × hpsi × hlam × hX → tX_4d
                                      ↓
(39) 生产/营销劳动需求 → hw_E_new1、hw_E_new
(40) 利润/研发劳动市场 → hw_R_new
(41)+(25) hPi/hw_R → 研发投入变化 → hN_new
(38) 家庭最终需求 + 中间需求 → hX_new
```

## 份额归一化为什么成立

基期生产地份额：

$$\psi_{mln}^j=\frac{X_{mln}^j}{\sum_lX_{mln}^j},\qquad \sum_l\psi_{mln}^j=1.$$

代码的相对份额：

$$\hat\psi_{mln}^j=\frac{\hat\xi_{mln}^{-\theta_j/(1-\rho_j)}}{\sum_l\psi_{mln}^j\hat\xi_{mln}^{-\theta_j/(1-\rho_j)}}.$$

因此真正的反事实份额是 `psi_prime_4d=psi_4d.*hpsi_4d`，沿生产国 `l` 加总为1。`hpsi_4d` 自己通常不沿 `l` 加总为1，因为它是“份额的相对变化”，不是份额水平。

同理，反事实母国采购份额是 `lam_prime_3d=lam_3d.*hlam_3d`，而不是 `hlam_3d` 本身。

## 不能从现有代码推出的内容

- 式 (16)–(23) 中连续企业积分、成本阈值与在位企业数的水平值没有逐企业实现；它们大多被校准的四维流量和份额吸收。
- `hgamma` 与论文式 (34) 的 `hat(xi)` 是成本还是效率的倒数，代码注释和论文符号方向需由作者的数据构造说明进一步确认。
- `Recompute_Equ.m` 对 `hw/beta/hP_int` 的 `repmat/permute` 次序与 `eqm_update` 不完全相同；未运行逐元素对照前不能宣称二者实现完全一致。
- 文档是静态公式映射，不构成运行时数值等价验证。
