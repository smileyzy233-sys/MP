# 写作标准

体裁为中文经济学研究方案的学术附录，重点是方法说明；沿用中文，不按英文期刊格式改写。文字基准为用户指定最终回复的“（2）具体步骤”，不照搬其全部内容或未核实数字。

每一节说明明确的工作对象、判断依据、处理方法和形成结果。相邻步骤解释任务差异；方法重复时简短回指，不重复整套程序。例子紧跟相应方法。公式之前交代用途，之后解释新符号和范围。

用“加总”“对应”“判断”“核查”“估计”表达具体动作。避免“打通、链路、闭环、口径对齐、映射桥梁、稳定载体”等密集技术标签；必要学术术语如固定效应、成本楔子、观测算子保留并解释。删除“不是X而是Y”的反复防御式句式。

正文为研究计划，不虚构已经执行、统计通过或数值结果。限制集中写在直接影响结论处，A.7提供检查方法。术语及符号遵循01_research_canon.md。
