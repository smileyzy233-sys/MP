# v3方法审查：企业识别、生产目标与结构成本反演

审查日期：2026-10-09。审查对象为当前《企业微观层面_新方案_框架重写版.docx》和《审稿人回复.docx》，直接读取两份Word的正文与原生公式。只在本文件提出修改意见，未改动源文件。

## 1. 最小且完整的研究设计

推荐保留三层分工：企业事件研究识别原有企业的调整；完整行业生产统计补充新进入和行业内重配置；结构模型计算与可用生产目标相对应的成本变化。三层分别说明样本、比较对象和假设，避免写成同一回归自然完成全部研究任务。

政策单元按版本独立编码，统一映射至固定GB2017（含2019修改单）。企业在每次改革前固定业务、地区及适用资格，再分别判断各政策版本下的待遇。事件编号可以连接同一次改革及其影响范围，但不能承担政策单元跨版本连接的功能。

基准采用企业—年份面板。GB四位小类—地区—年份面板用于完整生产变化的补充识别；它不是必须与微观回归得到相同数值的稳健性规格。两者的样本和估计对象不同，应分别表述。

## 2. 需要保留和改写的公式

### A.1—A.2：政策与企业

保留版本内的政策限制向量，索引改用版本v和本版本政策单元p。不能将z_pv直接当作一个小类的统一法律待遇，因为同一小类可能部分覆盖，且地区、资格及例外仍会改变适用状态。

企业业务的逐版判断可写为：

Z^k_fte = L^k(q_fe0, c_fe0, r_fe0, a_fe0; R_v(t)).

q为事件前固定业务，c为统一GB2017，r为事件前地区，a为适用资格，R为当期有效规则集合；L表示根据原文及有效规则作出的法律适用判断，不是新的结构函数。正文可以用一句自然语言说明，若符号过多则保留业务状态向量定义，将判断过程写成文字。

多业务权重仅在确有业务产出数据时使用。设ℓ为企业原始资料中可区分的业务—地区记录，w_fℓ,e0为其真实改革前产出比重，则Z_fte^k=Σ_ℓ w_fℓ,e0 z_fℓ,te^k。ℓ只在企业事件内识别原有业务记录，并非跨版本政策活动编号。权重指标用于衡量受影响业务的比重；若股比要求约束整个法人或项目，必须先判定法律适用关系，不能将不同业务股比要求平均为企业法律上限。未知业务不记零，已知部分权重不重新归一化。

### A.3.1：企业基准事件研究

非负生产价值可用以下PPML条件均值规格：

E[Q_ft | X,e] = exp{α_fe + λ_c(fe0),t,e + η_r(fe0),t,e + B'_fe0 π_te + Σ_(h≠−1) β_eh T_fe 1(t−t_e=h)}。

T_fe依据改革前业务的法律待遇变化确定，并在窗口内固定。企业固定效应、基期行业×年份和基期地区×年份各自控制稳定企业差异、行业共同变化和地区共同变化。B只含改革前特征。只有四位行业内部保留真实暴露差异时，四位行业×年份固定效应才可使用；完整覆盖全国一个小类的政策会被其吸收，需采用更粗行业×年份，并说明行业间比较所需的条件。

非负产出用PPML，持股、控制权、存续等结果另按变量性质选择估计方法，不必统一PPML。事件动态解释依赖乘法平行趋势、无未处理提前反应和明确的溢出假设，而非固定效应数量。已提前公告的改革应尽可能固定公告前业务，并区分公告与实施时间。

同一改革影响多个小类时，不将这些小类自动当成独立冲击。聚类依据共同政策决策、实施和误差相关性设置；小样本方法不能补足缺少的独立政策变动。六类限制共同变动时，主结果属于改革组合。

### A.3.3：产出与所有权

在同一固定原有企业集合内，可构造Y^F_ft=D^F_ft Q_ft、Y^D_ft=(1−D^F_ft)Q_ft。控制权变化改变两组产出归属，不改变企业是否属于原有企业样本。不要逐年按当期外资身份筛选两套企业面板。

逐企业估计Y^F和Y^D时，长期为零组可能因PPML分离被剔除。若采用按改革前GB、地区、处理状态固定的企业组汇总，应明确组内成员固定且仅代表原有企业。组不能由跨版本政策单元定义。样本剔除需核实，不能把估计器丢掉的企业视为未受影响。

完整行业生产应包含所有当期企业，按当期生产业务或可核实的统计行业口径归属：

F_ct=Σ_f D^F_ft Q_fct，D_ct=Σ_f(1−D^F_ft)Q_fct。

有分业务实际产出时按业务归属；只有企业总产出时使用与AMNE统计相容的企业行业归属，不能按候选代码等权拆分。企业暴露和固定效应保持基期分类，产出统计反映当期实际活动，二者不可混用。企业真实退出可记零，失访、披露中断和统计门槛变化不能直接记零。

多个GB映射同一部门时，先加总两组产出，再计算份额：M_jt=F_jt/(F_jt+D_jt)。一个GB对应多个ISIC、但候选最终都归入同一既有模型部门时，可在该部门聚合；候选跨模型部门且没有业务依据时，不拆分，也不重复计入。行业映射的不确定性可以不影响企业法律待遇识别，却会阻止精确部门成本反演。

## 3. 原有企业结果如何进入完整生产目标

原有企业生产不包括改革后新设企业。已有国内企业被外资收购仍属于原有企业面板，但新设法人没有改革前业务，不能补造其改革前暴露。因而企业事件回归即使识别充分，也不能直接产生完整AMNE部门生产目标。

完整行业补充分析的处理变量，可以是“该GB小类包含本次改革涉及的业务”。这个变量表示行业受到改革影响，不表示行业内每家企业待遇相同。其估计对象是整个小类的反应，包含改革覆盖业务、其他业务、竞争以及新进入；它需要行业之间的可比性，不是把企业精细匹配省略后仍得到同一结果。

建议在A.3.3中规定进入反演的次序：

1. 优先使用覆盖完整行业、可以可靠归并至模型部门的生产响应。
2. 若仅有受改革GB或固定企业集合结果，先明确覆盖范围及其余产出的处理假设，再形成部门目标。
3. 若完整生产、归属或补全依据仍不充分，只报告相应微观结果，不将原有企业反应外推为整个部门反应。

构造两种政策情景的预测产出时，固定估计样本、其他政策状态及协变量，仅改变已识别的改革项，并分别汇总外国和国内控制生产。固定效应下得到的是条件预测；若控制组也因改革受到影响，系数仍是相对变化，不自动等于处理组的全国均衡总变化。把样本之外产出保持不变是一项情景假设，应在形成目标时写清，而非在福利解释时才补充。

## 4. 成本反演与PE、GE

《审稿人回复》的实质改进是以可观察条款和经济流量反应为依据，取代将未解释残差整体归为制度成本。本研究应继承这一逻辑。回复稿的αΔDTA/κ形式则不能直接搬用：本研究使用事件效应、份额或相对生产，原模型弹性必须对应同一经济对象、价格口径及闭合方式。尤其不能直接认定θ/(1−ρ)就是所需生产弹性。

设δ_j=ln(d_j^1/d_j^0)，负值表示成本下降。ξ与成本的倒数关系保持不变：d^MP_imj=1/ξ_imj，dhat_Cmj=exp(δ_j)，ξhat_Cmj=exp(−δ_j)。共同δ_j对该部门外国母国适用同一成本变化，属于明确的基准假设；母国分组反演需要额外的独立生产目标。

保留模型求解反演的写法：

v(δ)=ΔO(G^χ(δ))−μhat，χ∈{PE,GE}；δhat=argmin_(δ∈D) v(δ)'Wv(δ)。

O将模型结果按实证口径汇总并作相同变换。它不能凭符号定义出模型本来没有的企业群体或细行业：当前模型若只有粗AMNE部门，就不能在GB内部复现处理、对照比较。此时应以已明确补全假设的部门生产目标进行情景反演，说明它是“使模型产生这一部门生产变化所需的成本调整”。不要再提出“增加活动组、校准替代弹性”来补足，因为本轮已明确不改变结构模型。

PE不因回归含行业×年份、地区×年份固定效应就自动成立。只有目标本身可解释为工资、价格和需求给定的生产反应时才使用PE。包含均衡调整的目标，在模型可以复现该目标范围和比较关系时使用GE反演。未能满足这一对应关系的部门，只做明确条件下的成本情景，不提升为全国政策福利的因果结果。

PE反演后投入GE所得产出通常会再次变化，不能要求它机械等于原PE目标；应报告两者差距及其来自均衡反馈的含义。GE反演则在同一闭合方式下匹配目标，再用相同成本冲击报告其余均衡结果。两种方法不能在文字上合并为“反演后再次计算GE”而不说明反演时是否已包含GE。

份额可作主目标，外国、国内及总产出用于检验单一成本机制。总产出是两者之和，不能视为额外独立信息；每个部门一个份额也不能识别多个母国成本或固定/边际成本。报告目标可达范围、拟合偏差、局部识别、边界解、多解及失败重复，而不是只保留有解部门。

## 6. 写作建议

每一步按“使用什么资料—怎样处理—得到什么结果—下一步如何使用”组织，先说明经济含义再给公式。依据《审稿人回复》的具体步骤部分，保留适量案例解释编码含义，并明确文本分类、政策暴露、经验效应和成本结果是不同对象。

可直接采用的成本段表述：

“本节根据改革带来的部门生产变化，计算跨国生产模型中的成本需要调整多少。先将外国和国内控制企业的生产价值统一到模型部门及计价口径，再改变外国企业在华生产的成本，直至模型产生与经验目标相符的生产变化。反演所得δ_j表示此次改革对应的成本变化；改革前的成本水平仍由模型基准数据和校准确定。”

以上最后一句不能被理解为已经识别全部历史制度成本。若模型基准成本包含其他因素，更清楚的写法是：“这一计算回答改革前后成本改变多少，基准成本还可能包含准入政策之外的因素。”只保留一种表述，避免连续用多句否定重复边界。

可直接采用的识别衔接表述：

“企业分析以改革前已经经营的企业为对象，考察其规模、控制权与存续变化。新设企业没有改革前业务记录，因此另利用完整行业统计估计进入及总生产变化。只有在生产范围、行业归属和比较条件能够与模型相对应时，才将这些结果用于部门成本反演。”

审查结论：重构方向可行。最应防止的错误是取消活动编号后保留无来源的活动面板，以及用存量企业DID直接代表全部门GE生产目标。遵守上述范围和对应条件后，可以保留当前模型及A.1—A.7结构，形成实证与结构两部分均清楚的v3。
