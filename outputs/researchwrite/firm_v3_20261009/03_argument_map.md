# 论证顺序

问题：准入规则改变如何影响企业所有权与在华生产，哪些生产变化能在既有跨国生产模型中解释为成本变化。

1. 政策文本逐版本编码，GB统一行业，企业固定业务确定实际法律待遇。
2. 固定业务前后待遇差定义改革，利用可比组识别原有企业反应；完整行业面板补充新进入和总生产。
3. 按当期真实业务/一致企业行业口径加总到AMNE模型部门，形成同一统计范围内有无改革生产结果。
4. 观测算子将经验比较与模型解对应，反演受改革部门成本；无法对应则保留微观结果或明确附加情景。
5. 用原模型成本/效率关系施加MP部门冲击，计算一般均衡结果。微观证据范围与结构假设分别说明。

主文先明确对象和步骤，再公式，再必要解释与边界。保留可执行的做法，删去反复的警告及实现细节。流程图突出企业与完整行业两个生产范围，不能画成企业估计自动推出全国部门成本。
