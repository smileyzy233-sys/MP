# A.1 政策文本的测量对象

## A.1.1 政策版本与政策编码单元

本文拟整理1995—2024年《外商投资产业指导目录》和全国外资准入负面清单，并结合其他有效规定，判断各时期的外资准入条件。各版本分别记录发布日期、生效日期和过渡安排；地区试点、特殊区域及投资者资格另行核实。政策年份用于标识文件版本，企业适用的政策则按实际生效时间确定。

政策编码单元是版本内能够独立判断准入条件的经济活动。同一条款涉及不同业务或适用条件时，按其法律含义拆分；同一业务受到多项限制时，完整保留各项要求。每个单元设置版本内编号 policy_unit_id，与原文及官方序号对应。不同版本分别编码，不建立政策单元之间的延续、拆分或合并关系。跨期比较以统一的行业分类和企业改革前业务为依据，具体方法见A.2。

政策状态依据实际法律效果确定。鼓励类业务仍可能受到股比或控制权约束；指导目录改为独立负面清单，也不必然改变企业准入条件。原条款在后续版本中未出现时，须结合当期有效规定，判断限制已经取消、转由其他规定实施，还是尚无法确认。数据库据此区分仍有限制、已核实取消、已核实无相应限制及状态未知，并保留判断依据。

表A1 政策编码单元的基本记录

| 记录内容 | 具体要求 |
|---|---|
| 版本及原文 | 政策名称、版本内编号、官方序号和原文位置 |
| 活动及限制 | 经济活动、六类限制及例外原文 |
| 适用条件 | 地区、投资者资格、业务或项目范围 |
| 适用时间 | 发布、生效日期及过渡安排 |
| 判断依据 | 法律状态、行业映射及人工核验记录 |

## A.1.2 限制变量的定义

设$v$为政策版本，$p$为版本内政策编码单元，其限制向量为：

$$z_{pv}=(P_{pv},E_{pv},C_{pv},O_{pv},G_{pv},R_{pv}).\tag{A2}$$

六类变量沿用原方案的经济含义，取值越大表示相应限制越强。各项要求同时记录适用条件；不同地区或投资者待遇不同时，分别判断。

表A2 外资准入限制变量

| 变量 | 限制内容 | 编码方法 |
|---|---|---|
| $P$ | 禁止准入 | 禁止为1，允许为0 |
| $E$ | 明确数值股比限制 | 1减外资总持股上限 |
| $C$ | 中方控制要求 | 要求中方控股、相对控股或主导时为1 |
| $O$ | 组织形式限制 | 要求合资、合作等特定形式时为1 |
| $G$ | 治理限制 | 对董事会、高管或法定代表人提出中方要求时为1 |
| $R$ | 其他有限限制 | 对数量、业务范围、地域或单一外商持股等提出要求时为1，并保留类别 |

原文规定外资总持股上限，或能够直接换算时，保留其原始数值$cap_{pv}$，并定义：

$$E_{pv}=1-cap_{pv}.\tag{A3}$$

经核实没有明确数值要求时，$E$记为0，原始上限不补填。“中方控股”等要求由$C$记录，不统一换算为49%；单一外商持股上限归入$R$。各维度的0均须有法律判断依据，未知状态保留缺失。禁止准入在A.4单列分析。

## A.1.3 政策文本抽取与人工审计

大语言模型辅助识别活动、限制、条件和例外，每项结果须对应政策原文。规则校验检查比例、日期和变量取值，人工复核重点检查条款拆分、限制取消、条件重合及低置信度结果，并随机抽取普通条款核验。模型版本、提示词和修改记录随编码结果保存。准确性以独立人工标注为标准，分别报告总体及复杂条款的精确率、召回率和F1；重复抽取的一致程度用于考察稳定性。

# A.2 从政策编码单元到企业政策暴露

## A.2.1 历史政策活动与GB2017四位小类匹配

本文统一采用GB/T 4754—2017及2019年第1号修改单，以下简称GB2017。需要分别核实政策生效时已经实施的行业标准、文件明确采用的分类依据和企业数据实际使用的行业版本，再将其转换至本研究的固定分类。三者可能不同。例如，2017年目录生效时实施的仍是GB2011，不能据目录年份认定其采用GB2017；企业数据采用何种标准，也应查阅相应统计说明。

基准方法从历史条款直接判断GB2017四位小类。首先，依据行业名称、注释及包括和不包括的活动建立检索资料；其次，以政策活动和适用范围检索候选代码；最后，由大语言模型结合原文与行业定义提出匹配判断，经人工复核后确定对应关系。语义相似度用于筛选候选，政策是否适用仍取决于业务内容及条款条件。

一个编码单元可以对应多个小类，一个小类也可以涉及多项规则。各对应关系分别记录完整覆盖、部分覆盖或范围待核实。只有相关活动的待遇均已确认且一致时，才形成统一的小类限制变量；存在差异时，保留各项规则及适用范围，供企业匹配使用。例如，水产品捕捞规则涉及0421海水捕捞和0422内陆捕捞，还须核查实际作业水域。2018、2020及2024年清单中的相关禁止规定持续存在，因此该例说明多行业映射，不构成这些版本之间的开放事件。

历史代码有明确依据时，再使用官方新旧类目对照表核验直接匹配结果。对照可能涉及GB1994、GB2002、GB2011和GB2017，各段关系分别核验，不要求所有条款依次经过全部版本。拆分或合并形成多个候选的，依据活动内容进一步判断；资料不足时保留候选，不指定无依据的唯一代码或分配权重。旧版条款的业务范围较宽、无法辨认后来的细分行业时，相应分类不确定性随记录保留。

## A.2.2 GB2017四位小类到ISIC Rev.4及AMNE部门

在GB2017分类基础上，依据官方对照资料转换至ISIC Rev.4四位行业，再按所用OECD-AMNE数据版本和现有模型部门表归并。分类版本、对应依据和未解决的关系一并保存。一对多候选最终属于同一模型部门时，可以确定部门归属；候选分属不同部门时，须由业务资料或分业务产出进一步判断。只有企业总产出且无法确定部门的记录，不任意拆分。该步骤服务于后续生产价值加总，企业实际适用的政策仍按具体业务判断。

## A.2.3 企业核心产品与政策编码单元的语义匹配

每次改革$e$以改革前企业核心产品或主营业务描述$q_{fe0}$为比较依据。已经提前公告的改革，优先使用公告前业务，同时固定相应地区和适用资格。企业行业统一至GB2017后，分别在各政策版本中检索相关单元，并检查一般规则及例外。业务文本与候选单元的相似度为：

$$s_{fpv,e}=\cos\!\left[\operatorname{emb}(q_{fe0}),\operatorname{emb}(A_{pv})\right].\tag{A4}$$

其中，$A_{pv}$为该版本单元的活动描述。匹配阈值由独立核验样本确定。存在多个合理候选时，结合业务细节及限制原文复核；多项规定同时适用时，完整记录各项要求。未找到条款的业务继续核查当期法律状态，不直接认定为无限制。

例如，普通小麦种子的商业繁育、生产可对应0511种子种苗培育活动。2018年清单对小麦、玉米要求中方控股，2020年小麦改为中方股比不低于34%，玉米仍要求中方控股。因此，应分别判断两类企业业务的待遇，不能将0511全部赋予同一变化。普通柴油货车与汽油乘用车均可能属于3611汽柴油车整车制造，但2020年两者面对的股比要求不同；相关开放安排已于2018年公告，企业业务基准也须考虑提前调整。

上述比较保持企业业务描述不变，逐版判断适用规则，无需连接前后政策单元。改革后的业务调整作为企业反应研究，不据此重新划分原有处理组。

## A.2.4 企业层面的六类政策暴露

对多业务、多地区企业，利用真实改革前产出确定业务和地区权重。设$\ell$为企业源数据中的业务—地区记录，$w_{f\ell,e0}$为其改革前产出占比，$z^k_{f\ell v(t),e}$为固定业务及资格在当期规则下适用的第$k$类限制，则：

$$Z^k_{ft,e}=\sum_{\ell}w_{f\ell,e0}z^k_{f\ell v(t),e},\qquad\sum_{\ell}w_{f\ell,e0}=1,\quad k\in\{P,E,C,O,G,R\}.\tag{A5}$$

业务记录仅对应企业自身资料，不作为跨版本政策活动编号。权重在事件窗口内固定，描述企业业务受到限制的程度。适用于整个法人或项目的股比要求，仍须按法律规则单独判断，不能把业务加权值当作法定持股上限。

无法取得分业务产出时，不构造平均权重或以文本相似度代替权重；主业明确的企业按已核实业务识别，混合业务企业单列。未知法律状态保留缺失，不通过重新调整已知业务权重将其消除。由此形成原有企业的政策暴露，供A.3识别其所有权和生产反应；改革后新设企业的生产另由完整行业统计纳入。
