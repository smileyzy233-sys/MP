## A.1　政策文本的测量对象

### A.1.1　政策版本与政策编码单元

政策数据库以正式生效的全国性外资准入规则为基础，负面清单实施前的年份用连续可比的《外商投资产业指导目录》衔接。各版本记录发布日期、生效时间和过渡安排，并结合地区试点、特殊区域和投资者资格，判断企业实际适用的规则。年内生效的改革按实际适用时间处理，过渡年度与完整年度分别分析。

政策编码单元是能够独立判断法律状态的最小经济活动。同一条文涉及不同限制或适用条件时分别编码；同一活动受到多类约束时，保留完整限制向量。版本内设置 `policy_unit_id` 定位原文，另设跨年稳定的 `activity_id`，追踪条款延续、修改、拆分、合并和删除。

条目删除后保留活动记录，核查原限制是否取消，或转入其他条款。确认取消时，将相应限制更新为0并保存依据；确认仍有限制时按现行规则编码；尚未查明时保留缺失。未列入清单的活动也须核实法律状态，不能仅凭未找到条目就记为无约束。

表A1　政策编码单元的最小字段

| 字段 | 内容及记录要求 |
|---|---|
| policy_year、measure_no | 政策版本年份及官方序号 |
| policy_unit_id | 版本内唯一编号及原文位置 |
| activity_id、version_link | 跨年活动编号及版本对应关系 |
| sector_heading、activity_text | 行业标题及活动原文 |
| restriction_text、exception_text | 限制及例外原文 |
| scope_text | 适用地区、投资者资格及其他前提 |
| effective_from、transition_text | 生效日期及过渡安排 |
| legal_status、status_evidence | 受限、取消、无对应限制或未知，以及判断依据 |
| match_status、review_record | 匹配状态、人工复核及修改记录 |

### A.1.2　限制变量的定义

活动$u$在地区$r$、年份$t$的限制向量为：

$$z_{urt}=(P_{urt},E_{urt},C_{urt},O_{urt},G_{urt},R_{urt}).\tag{P1}$$

六类变量按表A2编码，取值越大表示相应限制越强。不同投资者适用不同待遇时，分别记录其法律状态。

表A2　细活动层面的外资准入限制变量

| 变量 | 限制内容 | 基准编码 |
|---|---|---|
| P | 禁止准入 | 禁止为1，允许为0 |
| E | 明确数值股比限制 | 1减外资持股上限 |
| C | 中方控制要求 | 要求中方控股、相对控股或主导时为1 |
| O | 组织形式限制 | 要求合资、合作等特定形式时为1 |
| G | 治理限制 | 对董事会、高管或法定代表人提出中方要求时为1 |
| R | 其他有限限制 | 按数量、业务范围、地域、单一外商股比等分类，有要求时为1 |

股比数据库保留原始上限$\operatorname{cap}$。原文给出比例，或比例能够直接换算时，定义：

$$E_{urt}=1-\operatorname{cap}_{urt}.\tag{P2}$$

经核实没有明确数值股比要求时，$E$记为0，原始$\operatorname{cap}$不补填。“中方控股”等非数值要求由$C$记录，不换算为49%。单一外商持股上限归入$R$，与外资总持股上限分开。各维度的0表示已核实不存在该项限制，未知状态保留缺失。禁止准入另行分析，不按有限股比限制处理。

### A.1.3　政策文本抽取与人工审计

大语言模型（LLM）辅助抽取活动、限制和适用条件，每项判断保留原文依据。抽取结果通过规则校验和人工复核后进入数据库，并保存模型版本、提示词、原始结果及修改记录。

人工核验同时包括随机样本和复杂条款，重点检查比例、控制权、例外及条款删除。以人工标注为标准，分别报告总体和分层精确率、召回率及F1。重复抽取和不同模型的一致程度用于检查稳定性，不能代替准确性核验。

## A.2　从政策编码单元到企业政策暴露

### A.2.1　负面清单经济活动与 GB/T 4754 四位小类匹配

依据活动原文、例外和分类说明，确定最细可确认的GB/T 4754四位小类（GB4）。映射记录区分精确匹配、可缩窄候选范围的匹配及不确定匹配。限制仅覆盖某小类的部分活动时标记为部分覆盖，再核实企业业务是否属于该范围。行业代码用于寻找候选活动，不将同一小类的全部企业自动归为受限。分类版本变化时保留新旧代码对应关系。

### A.2.2　GB/T 4754 四位小类到 ISIC Rev.4

GB/T 4754与ISIC Rev.4并非等效分类。依据可复核对照表转换为ISIC四位代码，保留分类版本和转换依据。一对多关系先保留全部候选，只有活动原文足以支持时才缩窄；无法判断的记录进入人工复核。该转换用于统一行业信息并限定候选范围，不决定企业适用的法律状态。

### A.2.3　企业核心产品与政策编码单元的语义匹配

每次改革$e$以改革前企业核心产品或主营业务描述$q_{f,e0}$为匹配依据。候选集合来自跨年活动台账，包含限制已取消及经核实无对应限制的活动。根据行业信息缩小范围后，计算业务文本与活动文本的相似度：

$$s_{fu,e}=\cos\!\left(\operatorname{emb}(q_{f,e0}),\operatorname{emb}(A_u)\right).\tag{P3}$$

其中$A_u$为活动描述。模型和阈值由独立人工核验样本确定，主规格保持不变。相似度接近、存在多个合理候选或适用范围不明时，结合原文复核；该活动同时适用多项条款时，综合全部规则编码。改革后业务变化作为企业调整的结果，不用于重新确定原有企业的处理分组。

### A.2.4　企业层面的六类政策暴露

多业务、多地区企业按改革前真实产出构造活动与地区的联合权重$a_{fur,e0}$。第$k$类政策暴露为：

$$Z_{ft,e}^{k}=\sum_{u,r}a_{fur,e0}z_{urt}^{k},\qquad\sum_{u,r}a_{fur,e0}=1,\quad k\in\{P,E,C,O,G,R\}.\tag{P4}$$

式中政策状态按企业改革前的适用身份和投资者资格取值。权重及处理分组在事件窗口内固定，用于跟踪原有企业的控制权、存续、业务和产出变化。未知法律状态或未可靠匹配的业务单独记录，不记为零，也不通过重新归一化已知部分的权重消除缺失。新企业进入及当期生产重配置在后文的活动产出统计中纳入。独立政策变化由活动及改革决定，企业数量不能替代独立冲击数量。
