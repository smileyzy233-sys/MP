# 框架与排版约定

组织参考为旧版方案/企业微观层面.docx，其SHA256见source_manifest.json。保留附录标题、A.1至A.7七部分、16个子节及三张主表的位置。章节作用不变；A.3成本标题略去制度型一词，A.4删除企业路线用语，A.5.1明确为反演成本，以适应当前方法。具体方法以当前企业微观层面_新方案.docx为依据。

用户只要求采用旧框架，未要求旧稿外观。排版沿用当前新方案：单节Letter 8.5×11英寸，四边1英寸；宋体中文、Times New Roman拉丁正文12pt，1.4倍行距。当前Word样式、页面及页脚保留，正文槽全部重写。标题18pt，一级14pt，二级12.5pt，公式11.5pt、参考10.5pt。三线表沿用既有组件，表头重复，不设置固定行高。

正文创建基于当前Word副本，保留页面系统。原文、旧版原件不修改。内部MD只是写作源，不作为额外交付；不继承旧成本公式。原生OMML用已验证的TeX—MathML—Office转换路径，明确传递粗体、正体、花体及黑板体属性，避免向量与标量混淆。输出需检查章节、公式、表格编号及全页视觉。
