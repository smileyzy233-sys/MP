# 论证架构

研究问题：具体外资准入规则放松如何改变企业控制、进入与生产，其可识别生产响应在现有跨国生产模型中对应多大的成本相对变化？

核心主张：从可追溯的法律变化出发识别经济响应，再构造同口径的模型等价成本冲击。文本编码、因果识别和结构假设承担不同任务。

论证链：稳定活动法律面板 → 企业基期暴露与全部活动实际产出 → 真实改革组合事件识别 → 有支持的限制类型效果 → 观察算子一致的部门成本反演 → 条件一般均衡情景。

关键反论证：控制身份变化并非产出效率变化；改革针对性和对照溢出；约束共同变化；细活动处理在粗模型无法表达；经营与FDI固定进入不可分；结构零。

回应：多结果、多矩一致性核查、事件窗口、组合识别、明确分层结构规格、在不满足条件时报告微观结果并限制结构解释。
