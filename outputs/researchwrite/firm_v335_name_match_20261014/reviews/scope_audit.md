# 行业类别名称匹配：独立口径审查

审查依据为本轮当前 Word 的实际提取 `sources/actual_paragraphs.txt`（段号 0—204），以及主代理转发的最新用户七项要求。当前用户的新匹配标准优先于旧 AGENTS 和前轮方案；本审查没有重查来源、修改 Word 或执行匹配。

## 1. 应当统一的新口径

当前资料路径只有一条：企业 2010 年或更早行业代码 → 核实分类版本 → 取得该版行业类别名称 → LLM 比较名称与各版目录所述活动 → 保留对应条款及前后要求 → 判断本轮放宽并形成固定 Treat。真实业务文字作为未来可另行补充的资料，不与当前名称路径并列为基准。

LLM 判断类别名称与目录活动可以归为同一类时，该类别即纳入该条款的政策覆盖范围，类别判断赋予所属企业。名称口径采用一次复核、同版本同名称同口径复用。行业注释中的活动、包括与不包括项目不再用于把已匹配类别拆成甲乙企业，也不据此追加业务资料门槛或转为未知。

“名称匹配”“限制状态”“本轮放宽”必须分开：

| 层次 | 所回答的问题 | 必须保留的记录 |
|---|---|---|
| 名称匹配 | 所属类别名称是否与目录活动可归为同一类 | 原代码、分类版本、名称、条款位置、LLM 判断与复核依据 |
| 限制状态 | 命中条款规定什么准入条件 | 股比上限、合资合作、禁止等具体要求；鼓励资格另记；原文条件按原句记录 |
| 本轮放宽 | 前后要求是否发生本轮新增的实质改善 | 2007 目录、2011 草案和正式目录及相关有效规定的比较；实际新增放宽为 Treat=1，未放宽且符合对照定义为 0 |

股比上限提高后仍有限制，也可以属于放宽；名称命中或仍受限制本身都不等于 Treat=1。保留原条款中的限定语，是为了准确记载和比较法律要求，不是重新要求企业满足分类注释中各项实际业务细节。原文括号只修饰某子项、鼓励资格与准入限制不同、既有措施已提前生效等法律事实仍应解释清楚。

名称本身无法明确对应、行业代码/分类版本尚未确认时可以保留未知。政策比较尚未完成的记录应标明待核事实，不将其假定为未放宽。不要再把“已匹配类别包含不同具体活动”“无法排除其他业务受益”作为名称口径下的新增未知理由。

## 3. 需要随主段落一起同步的位置

- **摘要与问题定义：P3、15、19、23、24。**将“企业改革前业务受到放宽”统一到“企业改革前所属类别的政策暴露”。政策历史仍按目录原文比较；政策路径固定前期，部门路径使用当期。
- **数据说明：P28、59。**行业代码记录主要类别这一事实保留；其他业务另有资料的事实不再成为基准分组门槛。样本仍是 2010 年末已经经营的企业，名单由改革前资料确定。
- **法律比较：P64—66、68、91—92。**保留原条款、条件及有效规定；把“具体业务核实后才匹配企业”改为先完成名称类别赋值，再如实记录该条款法律要求及本轮变化。已知特殊安排和同期政策依已明确的比较口径处理，不借此恢复分类注释细分活动。
- **DID：P108、110、115—117、123—126。**估计对象是改革前所属类别被归为本轮放宽的企业相对于对照类别企业的变化。名称匹配复用结果不能被描述为企业实际产品差异。四位行业×年份可能完全吸收类别层处理，较宽行业×年份的比较依据与地区×年份的联合吸收要检查；聚类按赋值层级及误差相关结构设置。
- **同期政策：P128。**保留证券、自贸区、CEPA等具体法律事实及共同冲击讨论；前期名称暴露的赋值和真实资格材料的可得性分别表述，避免把“逐企完全核实全部资格”重新写成普遍匹配门槛。
- **部门路径：P95—102。**当期代码、版本、新旧转换、GB2017、ISIC、AMNE/模型部门逻辑保持。分类注释可用于解释 B 路径的多候选及转入关系；不能把 B 的映射困难反向改写为 A 的 Treat 未知。C4190/1363案例中的一对多、同部门可归并、跨部门待定仍有效。
- **部门目标与模型比较：P151、153、157—158、175。**Treat继续固定为改革前类别名称口径，生产部门采用当期归属。部门目标所依赖的处理/对照、共同系数或异质性系数，都继承这一新口径；相关模型比较组也相应采用类别暴露组。生产覆盖、最终控制、估值和总体反事实等条件不因名称匹配简化而消失。
- **实施及归类复核：P188—189。**顺序改为字段版本与名称核实、名称匹配复核、条款限制和放宽比较、固定处理身份、DID。严格/扩展样本若保留，应按名称匹配的明确程度或复核状态区分，不再按能否提供分类注释所列具体活动分层。

## 4. 一致性验收要点

1. 全文方法名称统一为“依据行业类别名称识别政策暴露”；实际限制、当前状态和本轮变化分别表达。
2. A 路径中不再出现“类别中甲活动受限、乙活动不受限，因此必须补企业业务才能分组”的步骤；同类判断后即形成类别覆盖。
3. 名称成功匹配之后，没有在多业务、其他未列明类别、地区资格或正文表注中重新加入同一套活动细分门槛。
4. B 路径保留合法的新旧对照、一对多及跨部门待定；A 赋值与 B 部门不互相替代。
5. 图A1、表A2、摘要、Treat定义、FE讨论和部门目标使用同一口径；公式符号的说明与之相符。公式本身不因名称路径变化而另造估计器。
6. 2011 信息公开及随后实施、2007—2014 窗口、2010 动态参照、单轮 DID、生产—成本—GE主线不变。当前任务仅修订方案，不形成匹配或实证结果。
7. 语言直接说明采用的资料和判断步骤；法律条件与估计含义各说明一次，避免再以重复否定句替代流程。

审查仅针对口径一致性。页眉、原生公式、图表可编辑性、分页控制及打开 Word 的验收由主代理实施，未在本文件宣称已完成。
