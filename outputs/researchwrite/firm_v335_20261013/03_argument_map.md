# 论证结构

研究问题：2011准入放宽如何改变改革前已有企业的生产与控制权，并在可验证的数据和模型条件下转化为部门跨国生产成本及一般均衡变化？

理论链：法律允许的外资参与范围扩大→控制权、投资与竞争反应→企业及行业生产构成变化→经部门口径与比较对象核对形成目标→模型依赖的等效MP成本→网络传导和福利。

关键张力：观察的是行业码、金额与直接资本来源，所需却是具体法律适用、可比生产、最终控制和部门总体。不能靠更多文本匹配消除缺失信息；不能靠一个成本参数掩盖微观与结构比较对象不同。

三层可交付研究：可靠识别的企业DID可以独立完成；部门生产需要覆盖和控制口径；结构反事实需要可比目标及被数据区分的参数。后层不成立时，保留前层实证，不强制外推。

结构：A.1问题机制与研究层次；A.2实际资料和变量；A.3法律识别与Treat；A.4分类转换和部门归属；A.5DID识别；A.6生产加总和2014目标；A.7成本反演、GE及实施顺序。
