# 语言与符号

中文经济学研究方案，方法说明为主，不按Nature英语论文体例。读者有基本经济学知识、不了解政策/税调/AMNE。连贯自然段为主，表格仅用于字段/状态比较，图示用于两路径衔接。

固定术语：外资准入放宽；企业处理身份Treat；行业类别/GB四位小类；模型部门；跨国生产(MP)；外国控制生产份额；等效MP成本；有改革/无本轮改革情景；泊松伪最大似然(PPML)；双重差分(DID)。

符号：f企业、t年、c行业小类、r地区、j模型部门、i生产国、m母国、n销售目的国、C中国；b(f)改革前较宽行业组，r_f0改革前地区。Q生产价值，R营业收入，D^F外国控制指示，F/D外国/国内生产，M份额，mu2014目标，delta成本对数变化，xi效率，d^MP=1/xi。X专用于结构流量；计量条件信息用Z，权重矩阵用W或Omega但不与福利混用。

避免：首先其次最后机械串联、不仅而且排比、空泛意义、全段否定、工程术语如管线/闭环/闸门；不使用“已验证”“稳健”描述未运行分析。已核事实用确定表达，推断说明依据，研究安排用“采用/拟/在…条件下”自然表达。

已知/假设/待查无需每句前贴标签，靠来源与动词明确。细排错、哈希和工具过程放内部QA，正文保留影响研究结论的限制。
