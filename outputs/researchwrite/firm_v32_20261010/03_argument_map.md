# 论证顺序

核心问题：一轮外资准入放宽如何影响原有企业行为及在华生产，这些生产变化能否支持部门跨国生产成本和一般均衡分析。

1. 官方目录、此前和随后规则说明法律变化；政策重要不证明DID可识别。
2. GB2017提供共同分类、改革前企业业务提供比较对象；政策机会变化决定Treat，实际利用机会是企业结果。
3. 企业DID在一个实施时点上比较，公告前资料分组，2014提前期单列，2015实施年年度暴露与完整年度区别，后续窗口按政策核查确定。
4. 样本支持与固定效应决定可识别范围；独立政策信息不能由企业或GB数量代替。
5. 分别估计外国和国内生产，检查预测范围。完整行业补充新设企业，两条证据不相加。
6. 可形成完整部门且期限与均衡条件可比才反演；保持既有成本效率传导。
7. 只比较所选改革有无的共同经济基准，其他年份/分类/累计变化均为可选扩展。
